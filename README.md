# fdthing
A graphical file finder, on top of fd


## Features
- Multiple directories search
- Group directories
- Case in/sensitive search
- Regex search
- Directories only search
- Extensions filter e.g. pdf, epub, azw3
- Exclude patterns e.g. **/folder, .epub
